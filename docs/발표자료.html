SafeReturn 솔루션

💡 핵심 아이디어

물건에 QR 스티커를 미리 붙여두면, 습득자가 스캔했을 때 개인정보 노출 없이 주인과 즉시 익명 채팅으로 연결됩니다.

👤

1단계 — 스티커 발급 (물건 주인)

물건 이름 + 연락처 + 비밀번호 입력 → 고유 QR 코드 생성 → 인쇄 후 물건에 부착

↓
📦

2단계 — 분실 발생

며칠 뒤 물건 분실 → QR 스티커가 붙어 있는 물건을 누군가 발견

↓
📱

3단계 — QR 스캔 (습득자)

핸드폰 카메라로 QR 스캔 → 안심 접수 페이지 자동 열림 (앱 설치 불필요)

↓
💬

4단계 — 익명 채팅 연결

"주인과 채팅하기" 클릭 → 채팅방 자동 생성 → 주인 대시보드에 실시간 알림

↓
🎉

5단계 — 물건 반환

채팅으로 장소 조율 → 편의점 택배함 / 지하철 보관함 등 비대면 반환 가능

구현된 주요 기능

기능 내용 특징
🔖 스티커 발급 물건 이름 + 연락처 + 비밀번호 입력 고유 ID(SR-XXXXXX) 자동 생성
📷 QR 코드 생성 실제 접속 가능한 URL이 담긴 QR 코드 즉시 생성 인쇄 기능 내장

🗑 스티커 삭제 대화 종료 후 스티커 및 채팅방 일괄 삭제 확인 팝업으로 실수 방지
📲 모바일 최적화 핸드폰에서 QR 스캔 후 바로 사용 가능한 반응형 UI 탭 전환으로 주인/습득자 화면 분리

기술 스택 및 아키텍처

⚛️ 프론트엔드

  • React 19 + TypeScript
  • Tailwind CSS v4
  • Framer Motion (애니메이션)
  • Lucide React (아이콘)

⚡ 빌드 / 라우팅

  • Vite 6 (빌드 도구)
  • Hash 기반 라우팅 (#/find/:id)
  • 별도 라우터 라이브러리 없음

🗄 백엔드 설계

  • Supabase (PostgreSQL)
  • Realtime WebSocket 구독
  • Row Level Security (RLS)

🔧 기타

  • QR 생성: api.qrserver.com
  • 현재: React State로 시뮬레이션
  • 배포: Google AI Studio
Hash 기반 라우팅 — QR 스캔 시 습득자 페이지 자동 진입
// QR 코드 URL 예시 http://192.168.36.194:3000/#/find/SR-721842 // 앱 로드 시 해시 파싱 const hash = window.location.hash; // "#/find/SR-721842" const itemId = hash.match(/^#\/find\/(.+)$/)?.[1]; // "SR-721842" // itemId가 있으면 → 습득자 전용 페이지 표시 // itemId가 없으면 → 주인 대시보드 표시

데이터베이스 설계 (1:N 관계)

📐 핵심 설계 원칙

물건 하나(items)에 여러 습득자가 각각 독립 채팅방(chat_rooms)을 생성할 수 있는 1:N 관계. 채팅방 안에 메시지들(chat_messages)이 쌓이는 구조.

📦 items — 분실물 스티커 테이블
🔑 id (SR-XXXXXX) name (물건 이름) contact (암호화된 연락처) password (관리용) created_at
↓ 1 : N
💬 chat_rooms — 익명 채팅방 테이블
🔑 id (UUID) 🔗 item_id → items.id created_at
↓ 1 : N
📨 chat_messages — 메시지 테이블
🔑 id 🔗 room_id → chat_rooms.id sender (owner/finder/system) message created_at
🔴 Supabase Realtime 활성화
chat_rooms / chat_messages 테이블에 INSERT 이벤트 발생 시 → 주인 대시보드가 WebSocket으로 즉시 수신 → 알림 표시 + 채팅 목록 자동 갱신
